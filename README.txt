موقع نيو لايف — نسخة HTML + CSS + JavaScript الكاملة

طريقة الرفع على GitHub Pages أو أي استضافة:
1. فك ضغط جميع الملفات (index.html, styles.css, app.js, products-fallback.js, products-data.json, Logo.png, privacy-policy.html, مجلد products).
2. يمكنك معاينة index.html مباشرة من جهازك أو رفع جميع الملفات داخل مستودع GitHub Pages.
3. تأكد في Firebase Authentication -> Authorized domains من إضافة الدومين الذي ترفع عليه الموقع ليعمل تسجيل الدخول بحساب Google.
